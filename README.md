# PSB-115: исследование признаков риска по 115-ФЗ

Проект посвящён поиску объяснимых признаков риска у юридических лиц по открытым
данным. Исходная выборка банка содержит 2009 компаний с датой возникновения риска
`risk_date`. Планируется исследовать бухгалтерскую отчётность, сведения ФНС,
арбитражные дела и данные ЕГРЮЛ, сравнить распространённость признаков с общей
совокупностью и проверить, видны ли они за один и два года до даты риска.

Результат первой итерации — проверенные критерии и их сочетания, описание
покрытия и ограничений, а также правила отбора компаний для проверки банком.
Подтверждённых примеров компаний без риска пока нет, поэтому оценка абсолютной
вероятности риска не входит в первую итерацию.

## Подготовка окружения

Для инструментов разработки используйте Python 3.11 или новее. Команды ниже
предназначены для PowerShell и выполняются из корня репозитория. Активация
виртуального окружения не требуется.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pre_commit install
```

Последняя команда устанавливает локальный обработчик Git: проверки будут
выполняться при `git commit`. Каждый участник выполняет её в своей копии
репозитория. При первом запуске pre-commit требуется доступ к сети для загрузки
окружения Ruff.

## Проверка и форматирование

[Ruff](https://docs.astral.sh/ruff/) используется и для проверки кода,
и для форматирования. Настройки задаются в `pyproject.toml`:

- целевая версия Python — 3.11;
- длина строки для форматирования — 100 символов;
- группы правил `E4`, `E7`, `E9`, `F` проверяют ошибки оформления и кода;
- `I` проверяет порядок импортов, `B` — частые ошибки,
  `UP` — использование современных конструкций Python;
- форматирование использует двойные кавычки и отступы пробелами.

Проверка без изменения файлов:

```powershell
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
```

Автоматическое исправление и форматирование:

```powershell
.\.venv\Scripts\python.exe -m ruff check --fix .
.\.venv\Scripts\python.exe -m ruff format .
```

Запуск всех проверок [pre-commit](https://pre-commit.com/) вручную:

```powershell
.\.venv\Scripts\python.exe -m pre_commit run --all-files
```

Перед коммитом сначала выполняется `ruff-check --fix`, затем `ruff-format`.
Если проверки изменили файлы, просмотрите изменения, добавьте их через `git add`
и повторите коммит. Пока Python-файлов нет, эти проверки пропускаются.
Версия Ruff в `requirements-dev.txt` и `rev` в `.pre-commit-config.yaml`
должны обновляться вместе.
